---
title: "商品列表 API"
description: "查询演示商品列表及其状态、价格。"
---

本接口仅用于本地演示，所有商品均为虚构数据。

## 查询商品

`GET /products`

本地地址为 `http://127.0.0.1:8000`，不需要身份验证。不传查询参数时，接口按默认顺序返回全部 8 条商品，包含所有状态。

```bash
curl 'http://127.0.0.1:8000/products'
```

## 查询参数

所有查询参数都是可选的。每个参数最多传一次，取值区分大小写。

| 参数 | 类型 | 取值 | 不传时 |
| --- | --- | --- | --- |
| status | string | `active`（在售）、`draft`（草稿）或 `archived`（归档）。只返回该状态的商品。 | 返回所有状态的商品 |
| sort | string | `price_asc`（按 `price_cents` 从低到高）、`price_desc`（按 `price_cents` 从高到低）或 `name_asc`（按 `name` 升序，按字符编码顺序比较，不是拼音顺序）。 | 保持默认顺序 |
| limit | integer | 1 到 100 的整数，表示最多返回的商品数量。 | 返回全部匹配的商品 |

接口按以下顺序处理参数：

1. 按 `status` 筛选商品。
2. 按 `sort` 对筛选结果排序。
3. 按 `limit` 截取排序后的前几条商品。

因此 `sort` 和 `limit` 一起使用时，返回的是排序后的前几条商品。`total` 为经过以上处理后实际返回的商品数量。

以下请求返回价格最高的 3 条在售商品：

```bash
curl 'http://127.0.0.1:8000/products?status=active&sort=price_desc&limit=3'
```

## 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | array | 商品列表 |
| data[].id | string | 商品唯一标识 |
| data[].name | string | 商品名称 |
| data[].status | string | active（在售）、draft（草稿）、archived（归档） |
| data[].price_cents | integer | 价格，单位为分，例如 2900 表示 29 元 |
| data[].currency | string | 币种，本演示为 CNY |
| total | integer | 本次响应中的商品数量，即经过筛选和截取后 `data` 的长度 |

## 错误响应

- `400`：查询参数无效，返回 `invalid_query` 和错误说明 `message`。以下情况都会返回该错误：
  - 传入了 `status`、`sort`、`limit` 以外的参数。
  - `status` 为空、不是 `active`、`draft`、`archived` 之一（包括大小写不符，例如 `ACTIVE`），或传了多次。
  - `sort` 为空、不是 `price_asc`、`price_desc` 或 `name_asc` 之一，或传了多次。
  - `limit` 为空、不是整数（例如 `1.5`、`-1` 或 `abc`）、小于 1 或大于 100，或传了多次。
- `404`：请求了不存在的路径，返回 `not_found`。
