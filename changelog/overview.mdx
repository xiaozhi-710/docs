<Update label="November 6, 2026">

## New features

- **Filter products by status**: `GET /products` accepts a `status` parameter (`active`, `draft` or `archived`) to return only products in that state. See the [products API](/autopilot-test/products).
- **Sort products**: Use the `sort` parameter to order results by price (`price_asc`, `price_desc`) or by name (`name_asc`, `name_desc`).
- **Limit results**: Use the `limit` parameter to return at most 1 to 200 products. Filtering runs first, then sorting, then the limit.

## Updates

- Invalid values for `status`, `sort` or `limit` return `400` with `invalid_query` and a message listing the accepted values.

</Update>
