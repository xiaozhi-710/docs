Les composants Mintlify vous permettent de créer des pages de documentation riches et interactives en utilisant MDX. Voici quelques-uns des plus couramment utilisés.

Consultez la [vue d'ensemble des composants](https://mintlify.com/docs/components) dans la documentation Mintlify pour une liste complète.

## Encadrés

Utilisez des encadrés pour attirer l'attention sur des informations importantes.

<Note>Un encadré **Note** sert à fournir des informations générales utiles au lecteur.</Note>

<Tip>Un encadré **Tip** met en avant un raccourci utile ou une bonne pratique.</Tip>

<Warning>Un encadré **Warning** signale un élément susceptible de poser problème.</Warning>

<Info>Un encadré **Info** apporte un contexte complémentaire.</Info>

```mdx
<Note>A **Note** is for general information that helps the reader.</Note>

<Tip>A **Tip** highlights a helpful shortcut or best practice.</Tip>

<Warning>A **Warning** flags something that could cause problems.</Warning>

<Info>An **Info** callout provides supplementary context.</Info>
```

  </Card>
  <Card title="Démarrage rapide" icon="rocket" href="/fr/quickstart">
    Lancez votre documentation en trois étapes.
  </Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="API Reference" icon="terminal" href="/api-reference/introduction">
    Auto-generated docs from your OpenAPI spec.
  </Card>
  <Card title="Quickstart" icon="rocket" href="/quickstart">

  </Card>

```

Utilisez `<Columns cols={N}>` pour contrôler la largeur de la grille. Les cartes sans `href` s'affichent comme des panneaux d'information.

## Étapes

Les étapes présentent clairement des procédures numérotées.

<Steps>
  <Step title="Installer le paquet">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="Initialiser">
    Exécutez la commande d'initialisation à la racine de votre projet.
    ```bash
    npx my-package init
    ```
  </Step>
  <Step title="Vous êtes prêt">
    Commencez à utiliser le paquet dans votre code.
  </Step>
</Steps>

````mdx
<Steps>
  <Step title="Install the package">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="Initialize">
    Run the init command in your project root.
  </Step>
  <Step title="You're ready">
    Start using the package in your code.
  </Step>
</Steps>
````

<Tabs>

    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add my-package
    ```
  </Tab>
</Tabs>

## Accordéons

Les accordéons masquent le contenu derrière un bouton — utile pour les FAQ ou les détails optionnels.

<AccordionGroup>
  <Accordion title="Que fait ce produit ?">
    Une réponse brève à la première question. Restez concis.
  </Accordion>
  <Accordion title="Comment le prix est-il calculé ?">
    Une autre réponse ici. Utilisez autant d'espace que nécessaire.
  </Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="What does this product do?">
    A brief answer to the first question.
  </Accordion>
  <Accordion title="How is pricing calculated?">
    Another answer here.
  </Accordion>
</AccordionGroup>
```

## Cadres

Encapsulez des images ou d'autres contenus dans un `Frame` pour ajouter une bordure stylisée et des coins arrondis.

<Frame>
  <img src="https://mintlify-assets.b-cdn.net/bigbend.jpg" alt="Paysage de Big Bend" />
</Frame>

```mdx
<Frame>
  <img src="/images/screenshot.png" alt="App screenshot" />
</Frame>
```

## Groupes de code

`CodeGroup` affiche plusieurs extraits de code sous forme d'onglets — idéal pour présenter le même exemple dans plusieurs langages.

<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  const users = await response.json();
  ```

  ```python Python
  import requests
  response = requests.get('https://api.example.com/users')
  users = response.json()
  ```

  ```bash curl
  curl https://api.example.com/users
  ```
</CodeGroup>

````mdx
<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  ```

  ```python Python
  response = requests.get('https://api.example.com/users')
  ```
</CodeGroup>
````
